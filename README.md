# AI 知识测验 · 26 题

Klein-Avraham 等（2026）性能本位 AI 知识量表的中文自测网页。

## 这是什么

把 Klein-Avraham, Ston, Atias, Roll & Baram-Tsabari（2026）在 *Computers & Education* 发表的 AI 知识量表做成交互式网页，答完自动判分，并与原文 800 人常模比对。

量表采用双轴框架。

- **知识类型轴（CPE）**：内容知识、程序知识、认知知识
- **知识领域轴（TUS）**：AI 技术、AI 与用户、AI 与社会

两轴交叉形成 3×3 结构，共 26 题。

## 用法

直接打开 GitHub Pages 页面作答。选好答案后点“交卷”，逐题显示对错与原文正确率，并给出按知识类型、按知识领域的分项得分。

## 关于题量

原文初拟 27 题，其中原第 14 题在验证性因子分析中因子载荷过低被剔除，正式量表为 26 题。本卷题号沿用原文编号，因此第 14 号空缺。

## 几点说明

- 题目由原文 Table 2 逐条转录并译为中文。用于正式施测需做翻译与回译，并重新检验信效度。
- 原文 Cronbach's α 总量表为 0.817，三个领域子量表分别为 0.627、0.684、0.497。社会领域子量表信度偏低，引用时需说明。
- 常模均值 15.42、标准差 5.14，按原文 27 题口径统计，仅供参考。
- 本页面仅供学习自测，不作研究数据来源。
